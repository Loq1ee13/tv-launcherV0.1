# Легкий лаунчер для телевізора

Простий головний екран для Android TV / Google TV у стилі iOS. Без реклами і без рекомендацій.

**Вигляд:** кольорові шпалери, напівпрозорі віджети-картки зверху, сітка іконок з заокругленими кутами посередині і док унизу. Іконка під фокусом трохи піднімається й підсвічується білою рамкою. Біля нових програм стоїть синя крапка.

**Віджети (зверху)**
- **Годинник і дата.** Якщо увімкнено таймер сну, поруч видно, скільки хвилин лишилося.
- **Погода:** зараз і на 3 дні вперед. Оновлюється раз на 30 хвилин. Натисни на віджет, щоб змінити місто (за замовчуванням Львів).
- **Курс НБУ:** долар і євро. Оновлюється раз на 3 години.
- **Пам'ять:** вільне місце й оперативна пам'ять. Коли місця менше 1.5 ГБ, віджет жовтіє. Натисни, щоб відкрити очищення пам'яті.

**Док (знизу):** YouTube без реклами, Браузер, Рекомендовані, Меню.

**Меню**
- 🌙 **Таймер сну** (про нього нижче).
- 🖼 **Шпалери**: 6 готових кольорових варіантів (Сутінки, Океан, Захід сонця, Ліс, Аврора, Графіт) або своє фото.
  - «Вибрати файл» відкриває системне вікно вибору файлу.
  - «Зі списку фото» показує фото з пам'яті ТВ і з флешки. Першого разу телевізор попросить дозвіл на доступ до фото.
  - Фото копіюється в лаунчер, тож флешку потім можна витягнути.
  - Фото з телефона зручно передати через **Send Files to TV**.
- 🔠 **Розмір іконок**: маленькі (10 у ряд), звичайні (8 у ряд) або великі (6 у ряд, краще видно з дивана).
- 🧹 **Очищення пам'яті** (те саме відкривається натисканням на віджет «Пам'ять»):
  - «Звільнити оперативну пам'ять» закриває фонові процеси програм. Це найкраще допомагає, коли телевізор почав гальмувати. Програма, яка зараз відкрита, не постраждає.
  - «Очистити кеш програм» показує програми від найбільшого кешу до найменшого. Обираєш програму, і відкриваються її налаштування з кнопкою «Очистити кеш». Щоб бачити розміри кешу, лаунчеру потрібен дозвіл «Доступ до використання», він сам підкаже, де його дати. Якщо екрана дозволу на ТВ немає, дай дозвіл з комп'ютера:
    ```
    adb shell appops set ua.tvlauncher GET_USAGE_STATS allow
    ```
    Без дозволу список теж працює, просто без розмірів.
  - Очистити кеш чужих програм одним натисканням Android не дозволяє жодній програмі, тому кеш очищається вручну, по кнопці в налаштуваннях кожної програми.
- 📦 **Рекомендовані програми**, 🌤 **місто для погоди**, 👁 **приховані програми**, ⚙️ **налаштування ТВ**.

Інтернет лаунчер використовує тільки для погоди й курсу (Open-Meteo і НБУ). Реєстрація і ключі для них не потрібні.

**Таймер сну.** Меню → Таймер сну → обери час. Першого разу телевізор попросить дозвіл «адміністратора пристрою». Він потрібен лише для того, щоб вимкнути екран у призначений час, інших прав не дає. Якщо вікно дозволу не з'являється, дай дозвіл з комп'ютера:
```
adb shell dpm set-active-admin ua.tvlauncher/.SleepAdmin
```
Таймер спрацьовує приблизно: система може затримати його на хвилину-дві.

> Щоб видалити лаунчер, спершу зніми цей дозвіл: Налаштування → Безпека (або Конфіденційність) → Адміністратори пристрою → «Таймер сну».

**Сітка програм.** Тут видно всі встановлені програми. Нова програма з'являється одразу після встановлення: телевізор покаже повідомлення «Додано на головний екран», а сама програма 3 дні стоїть першою з синьою крапкою перед назвою. Видалені програми зникають із сітки самі.

**Рекомендовані програми.** Іконка «Рекомендовані» в доку (або Меню → Рекомендовані програми) відкриває список корисних програм: Send Files to TV, X-plore, VLC, Kodi, AirScreen, TV Bro, Downloader, Київстар ТБ, MEGOGO, SWEET.TV, AdGuard.
- ✅ означає, що програма вже встановлена: натисни, щоб відкрити.
- ⬇️ означає, що її ще немає: натисни, і відкриється сторінка в Google Play.
- AdGuard ставиться з офіційного сайту через браузер, лаунчер підкаже кроки.

**YouTube і Браузер у доку:**
- **YouTube** відкриває **SmartTube**, YouTube для ТВ без реклами.
- **Браузер** відкриває **TV Bro**, браузер для пульта з вбудованим блокуванням реклами.

Якщо програму ще не встановлено, іконка підкаже, як її поставити:
- **TV Bro** є в Google Play, іконка відкриє сторінку встановлення.
- **SmartTube** у Google Play немає. Встанови програму **Downloader** (від AFTVnews) з Google Play, відкрий її і введи код **28544**. Іконка покаже ці кроки й відкриє Downloader.
- Став SmartTube тільки з офіційного джерела (GitHub: yuliskov/SmartTube). Якщо в тебе вже стоїть стара версія, онови її до останньої.

Після встановлення іконки в доку самі підхоплять програми, нічого налаштовувати не треба.

**Керування пультом**
- **OK** — відкрити програму
- **Довге натискання OK** — сховати програму з екрана або відкрити «Про програму» (видалити, очистити кеш)
- **Вниз** — док (YouTube, Браузер, Рекомендовані, Меню)
- **Вгору** — віджети погоди й пам'яті

## Крок 1. Зібрати APK (без встановлення програм на комп'ютер)

1. Зареєструйся на [github.com](https://github.com) (безкоштовно).
2. Натисни **+** → **New repository**, назви, наприклад, `tv-launcher`, натисни **Create repository**.
3. На сторінці репозиторію натисни **uploading an existing file**.
4. Розпакуй архів і перетягни у вікно браузера **вміст** папки `TvLauncher` (папки `app`, `.github` і файли поруч), потім **Commit changes**.
   - Папка `.github` прихована. У Windows: Провідник → «Вигляд» → «Приховані елементи». На Mac: `Cmd + Shift + .`
   - Перевір, що в репозиторії є файл `.github/workflows/build.yml`. Без нього збірка не запуститься.
5. Відкрий вкладку **Actions**. Збірка стартує сама й триває 3–5 хвилин.
6. Коли з'явиться зелена галочка, відкрий збірку і внизу в розділі **Artifacts** завантаж `tv-launcher-apk`. Усередині zip буде `app-debug.apk`.

*Альтернатива:* відкрити папку в Android Studio і натиснути **Build → Build APK(s)**.

## Крок 2. Встановити на телевізор

**Варіант А: флешка**
1. Скопіюй `app-debug.apk` на флешку і встав у телевізор.
2. Відкрий файл через файловий менеджер ТВ (якщо його немає, постав з Google Play «File Commander» або «X-plore»).
3. Коли телевізор попросить, дозволь цьому файловому менеджеру встановлювати програми з невідомих джерел.

**Варіант Б: через ADB з комп'ютера**
1. На ТВ: Налаштування → Система → Про пристрій → 7 разів натисни «Збірка ОС».
2. Налаштування → Система → Для розробників → увімкни **Налагодження USB / мережеве налагодження**.
3. Дізнайся IP телевізора (Налаштування → Мережа).
4. На комп'ютері встанови [Android platform-tools](https://developer.android.com/tools/releases/platform-tools) і виконай:
   ```
   adb connect 192.168.X.X
   adb install app-debug.apk
   ```
   (на телевізорі підтверди запит на підключення)

## Крок 3. Зробити його головним екраном

Спершу просто натисни **Home** на пульті. Якщо з'явиться вибір «Який лаунчер використовувати», обери **Легкий лаунчер → Завжди**. Готово.

Якщо вибору немає (так зазвичай буває на Google TV), зроби це через ADB:

**Спосіб 1 (м'який, нічого не вимикає):**
```
adb shell cmd package set-home-activity ua.tvlauncher/.MainActivity
```

**Спосіб 2 (якщо спосіб 1 не спрацював): вимкнути стандартний лаунчер**
```
adb shell pm list packages | grep -i launcher
```
(у Windows замість `grep -i launcher` використовуй `findstr launcher`)

Часто це `com.google.android.apps.tv.launcherx` (Google TV) або `com.google.android.tvlauncher` (Android TV). Вимкни знайдений пакет:
```
adb shell pm disable-user --user 0 НАЗВА_ПАКЕТА
```

**Як усе повернути назад:**
```
adb shell pm enable НАЗВА_ПАКЕТА
```
Або просто видали «Легкий лаунчер» у налаштуваннях програм. Нічого незворотного тут немає.

> На деяких Google TV при вимкненому стандартному лаунчері зникає швидке меню вибору джерела (HDMI). Тоді джерело перемикається кнопкою Input на пульті або через Налаштування.
